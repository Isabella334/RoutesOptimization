# 🚀 Route Optimization Web App (Genetic Algorithm)

A full-stack web application that computes and visualizes the optimal route between multiple destinations using a **Genetic Algorithm**. The system allows users to input up to **15 destinations within a 100 km radius**, processes the optimization in the cloud, and displays the best route on an interactive map.

---

## 📌 Features

- 📍 Input up to 15 destinations
- 🧠 Route optimization using a Genetic Algorithm
- ☁️ Cloud-based computation for scalability
- 🗺️ Interactive map visualization with markers
- 🔐 User authentication
- ⚡ Fast and responsive UI

## 📐 Constraints

- Maximum of **15 destinations**
- All points must be within a **100 km radius**
- Optimization is based on minimizing total travel distance
